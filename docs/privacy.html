Privacy Policy

Personal use

Mind Scale Studio is currently a personal project operated for the owner’s own use. It does not provide accounts, services, or access to third-party users.

Pinterest API use

Mind Scale Studio may use Pinterest API credentials to publish original content to the owner’s own Pinterest account. Any Pinterest data accessed is used only to operate and manage that account.

Data practices

Mind Scale Studio does not sell personal data. It does not use Pinterest data for advertising, profiling, or resale, and it does not intentionally share that data with third parties.

Credential security

API credentials are stored locally and are not intentionally shared publicly. Reasonable care is taken to keep credentials out of public source code and published website files.

Changes

This policy may be updated if Mind Scale Studio’s features or data practices change. The date above identifies the latest version.
